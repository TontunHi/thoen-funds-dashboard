# Domain Glossary

- **Spreadsheet ID**: The unique identifier in the Google Sheets URL (`1tEBhzMWF7QkwOEBXamCImWrbcOqthdb2Kb9Wgs6k04I`).
- **Sheet GID**: The specific worksheet/tab ID (`806124582`).
- **Merged Cell (Span)**: A rectangular region of table cells combined into a single visual cell, represented by `rowspan` and `colspan` in HTML table rendering.
- **Google Sheets API v4**: Google's REST API endpoint returning full grid data, cell values, background colors, text formats, alignments, borders, and `merges` metadata.
- **Light Mode UI**: Clean, bright visual interface optimized for dashboard visibility and full-page vertical scrolling without nested layer containers or horizontal scrollbars.
- **Auto-Refresh / Polling**: Background periodic data fetching (every 60s) with live status indicator and manual reload trigger.
